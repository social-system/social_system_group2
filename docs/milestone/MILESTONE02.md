# MILESTONE02: レシート詳細取得の CRUD 処理を追加

## 目的

指定した ID のレシートを、明細付きで取得できる DB 操作を追加する。

このマイルストーンでは API ルートは追加しない。CRUD 層に詳細取得処理を追加することだけを目的とする。

## 対象範囲

`receipt_id` を受け取り、該当する `Receipt` を取得する CRUD 関数を追加する。

関連する `ReceiptItem` も取得できる状態にする。

存在しない ID の場合は、呼び出し元が `404 Not Found` を返せるように `None` を返す。

## 想定変更ファイル

`app/crud/` 配下のレシート関連ファイル。

必要に応じて、SQLAlchemy の取得方法に合わせて `app/receipts/models.py` を確認する。

## 仕様

関数名は既存の CRUD 命名に合わせる。

候補名は `get_receipt` または `get_receipt_by_id` とする。

引数は DB セッションと `receipt_id` とする。

戻り値は `Receipt | None` とする。

明細はレスポンス作成時に参照できる状態にする。

## 受け入れ条件

存在する ID を指定すると、親レシートと明細を取得できる。

存在しない ID を指定すると `None` を返す。

既存の登録 API の動作を壊さない。

## 実装上の注意

このマイルストーンでは API ルートを追加しない。

このマイルストーンでは一覧取得、削除、テスト基盤は追加しない。

N+1 問題を避けられるなら、SQLAlchemy の `selectinload` などを使ってよい。ただし既存構成に対して過剰な抽象化は追加しない。
