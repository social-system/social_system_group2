# MILESTONE08: テスト用 DB 設定を追加

## 目的

テストが本番用の `receipts.db` に依存しないようにする。

安全に自動テストを実行できる土台を作る。

## 対象範囲

pytest のテスト基盤を追加する。

FastAPI の `get_db()` 依存性をテスト用 DB に差し替える。

テストごとに独立した DB 状態を作る。

## 想定変更ファイル

`tests/conftest.py`

必要に応じて `pyproject.toml`

必要に応じて `app/db/session.py`

## 仕様

テストでは本番用の `receipts.db` を使わない。

SQLite のテスト DB を使う。

候補は、インメモリ SQLite または一時ファイル SQLite とする。

SQLAlchemy と FastAPI の依存性注入を使い、テストクライアントから API を呼べるようにする。

## 受け入れ条件

`uv run pytest` を実行できる。

テスト実行で本番用 `receipts.db` が作成、更新、削除されない。

テスト用クライアントから FastAPI API を呼べる。

テストごとに DB 状態が独立している。

## 実装上の注意

このマイルストーンでは、テスト基盤の追加を主目的とする。

登録、取得、削除などの本格的なテストケースは MILESTONE09 で追加する。

既存コードをテストしやすくするための最小限の変更は許可するが、大きな設計変更はしない。
