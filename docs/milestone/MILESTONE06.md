# MILESTONE06: レシート削除の CRUD 処理を追加

## 目的

指定した ID のレシートを削除する DB 操作を追加する。

このマイルストーンでは API ルートは追加しない。CRUD 層に削除処理を追加することだけを目的とする。

## 対象範囲

`receipt_id` を受け取り、該当する `Receipt` を削除する CRUD 関数を追加する。

存在しない ID の場合は、呼び出し元が `404 Not Found` を返せるようにする。

親レシート削除時に、関連する明細も削除されることを前提にする。

## 想定変更ファイル

`app/crud/` 配下のレシート関連ファイル。

必要に応じて、`app/receipts/models.py` の cascade 設定を確認する。

## 仕様

関数名は既存の CRUD 命名に合わせる。

候補名は `delete_receipt` とする。

引数は DB セッションと `receipt_id` とする。

削除できた場合は削除した ID、または削除済みであることが分かる値を返す。

存在しない ID の場合は `None` または `False` を返す。

## 受け入れ条件

存在する ID を指定すると、親レシートを削除できる。

親レシート削除時に、関連する明細も削除される。

存在しない ID を指定すると、API 層が `404 Not Found` を返せる状態になる。

既存の登録 API、詳細取得 API、一覧取得 API の動作を壊さない。

## 実装上の注意

このマイルストーンでは API ルートを追加しない。

このマイルストーンではテスト基盤は追加しない。

削除時に明細を個別に手動削除する必要があるかどうかは、既存の cascade 設定を確認して判断する。
